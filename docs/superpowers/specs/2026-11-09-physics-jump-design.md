# 큐브 오픈월드 — 1차 조각: 물리와 점프

## 의도
귀여운 3D 큐브가 끝없는 오픈월드를 탐험하는 웹 게임. 혼자 즐기거나 링크로 지인에게 뿌리는 작은 프로젝트라서
**손맛과 분위기**가 최우선이다. 이 조각은 그 토대인 "물리와 점프"만 다룬다.

## 결정
- Three.js + TypeScript + Vite, 정적 단일 HTML 빌드(링크 배포).
- 물리는 직접 구현(A안). 고정 60Hz 시뮬레이션, 렌더는 보간.
- 지면은 지형 높이 함수 `height(x, z)`를 직접 조회한다. 충돌 메시 없음.
- 물리는 `PhysicsWorld` 뒤에 두어 나중에 Rapier로 일부 교체 가능하게 한다.

## 범위
큐브 1개, 노이즈 임시 지형(청크 시스템은 다음 조각), WASD/방향키 + 터치 조이스틱/점프 버튼, 추적 카메라.

## 구성
- `physics/`: 중력, 지면 판정, 경사 처리, 코요테 타임, 점프 입력 버퍼, 가변 점프 높이, 고정 스텝 누산기.
- `terrain/height.ts`: 시드 기반 fBm 노이즈. 물리와 렌더가 같은 함수를 쓴다.
- `terrain/mesh.ts`: 플레이어 주변에 격자를 따라붙이는 임시 렌더 지형.
- `cube/`: 둥근 큐브, 얼굴, 스쿼시/스트레치, 그림자.
- `input/`: 키보드와 터치를 같은 입력 형태로 합친다.

## 완료 기준
- 주사율과 무관하게 같은 점프 높이/시간 (단위 테스트로 검증).
- 언덕에서 파고들거나 떨리지 않음.
- 폰 브라우저에서 조작 가능.
