# 큐브 월드

귀여운 3D 큐브가 끝없는 세상을 돌아다니며 별 조각을 모으는 웹 게임. Three.js + TypeScript + Vite.
빌드 결과는 파일 하나(`dist/index.html`)라서 어디에든 올려 링크로 나눌 수 있다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 단위 테스트
npm run build    # dist/index.html 한 파일로 빌드
```

## 조작

| | 키보드/마우스 | 터치 |
|---|---|---|
| 이동 | WASD, 방향키 | 왼쪽 스틱 |
| 점프 | 스페이스 (길게 누르면 높이 뜀) | 점프 버튼 |
| 시점 | 마우스 드래그, Q/E | 화면 드래그 |
| 시간 빨리감기 / 소리 | T / M | 상단 버튼 |

## 구조

| 폴더 | 역할 |
|---|---|
| `src/physics` | 고정 60Hz 물리. 중력, 가변 점프, 코요테 타임, 점프 버퍼, 비탈, 나무/바위 충돌, 물에 뜨기. 손맛 상수는 `world.ts` 맨 위. |
| `src/terrain` | 시드 기반 높이 함수. 물리와 렌더링이 같은 함수를 쓴다. |
| `src/world` | 청크 스트리밍, 나무/바위/별 배치(좌표+시드로 결정), 물, 별 렌더링. |
| `src/sky` | 낮밤 순환(순수 함수), 하늘/해/달/별/구름. |
| `src/audio` | WebAudio로 합성하는 효과음, 환경음, 오르골 멜로디. 소리 파일 없음. |
| `src/fx` | 먼지/물보라/반짝임 입자. |
| `src/cube`, `src/input`, `src/hud.ts` | 큐브, 입력, 화면 UI. |

진행(모은 별)은 브라우저 `localStorage`에 저장된다. 저장소를 못 쓰는 환경에서도 게임은 정상 동작한다.
