# 큐브 월드

귀여운 3D 큐브가 끝없는 세상(바다, 강, 산, 여덟 가지 생태계, 마법 지대)을 돌아다니며 별 조각을 모으는 웹 게임. Three.js + TypeScript + Vite.
빌드 결과는 파일 하나(`dist/index.html`)라서 어디에든 올려 링크로 나눌 수 있다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 단위 테스트
npm run build    # dist/index.html 한 파일로 빌드
```

## 조작

| | 키보드/마우스 | 터치 |
|---|---|---|
| 이동 | WASD, 방향키 | 왼쪽 스틱 |
| 점프 | 스페이스 (길게 누르면 높이 뜀) | 점프 버튼 |
| 시점 | 마우스 드래그, Q/E | 화면 드래그 |
| 시간 빨리감기 / 소리 | T / M | 상단 버튼 |

## 구조

| 폴더 | 역할 |
|---|---|
| `src/physics` | 고정 60Hz 물리. 중력, 가변 점프, 코요테 타임, 점프 버퍼, 비탈, 나무/바위 충돌, 물에 뜨기. 손맛 상수는 `world.ts` 맨 위. |
| `src/terrain` | 시드 기반 지형: 대륙/섬/바다, 언덕, 산악, 강, 기후에 따른 생태계(초원·벚꽃 숲·단풍 숲·사막·열대·설원)와 마법 지대(크리스탈 평원·버섯 숲). 물리와 렌더링이 같은 함수를 쓴다. |
| `src/world` | 청크 스트리밍, 생태계별 나무/바위/수정/버섯, 마법진 점프 패드, 떠다니는 섬, 별 배치(좌표+시드로 결정), 물, 렌더링. |
| `src/sky` | 낮밤 순환(순수 함수), 하늘/해/달/별/구름/오로라/무지개. |
| `src/audio` | WebAudio로 합성하는 효과음, 환경음, 오르골 멜로디. 소리 파일 없음. |
| `src/fx` | 먼지/물보라/반짝임 입자. |
| `src/cube`, `src/input`, `src/hud.ts` | 큐브, 입력, 화면 UI. |

진행(모은 별)은 브라우저 `localStorage`에 저장된다. 저장소를 못 쓰는 환경에서도 게임은 정상 동작한다.

## 월드 둘러보기

- 시작 지점 근처에는 초원과 첫 마법진(점프 패드)이 있다. 마법진을 밟으면 하늘 높이 날아가고, 위에 떠 있는 큰 별을 먹을 수 있다.
- 시작 지점에서 약 100~250m 떨어지면 크리스탈 평원과 버섯 숲이 나온다. 밤에 더 밝게 빛난다.
- 바다는 어디서나 헤엄칠 수 있고(큐브가 수면에 뜬다), 저지대에는 강이 굽이쳐 흐른다.
- 마법 지대에서는 밤에 반딧불이 날고, 밤하늘에는 오로라가, 해가 낮을 때는 무지개가 뜬다.
