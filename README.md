# 큐브 어스

실제 지구를 큐브가 되어 걸어 다니는 웹 게임. Three.js + TypeScript + Vite.
지구는 둥근 구이고, 걸어서 한 바퀴 도는 데 약 1시간(달리면 30분) 걸린다. 뉴욕 타임스스퀘어에서 출발한다.
빌드 결과는 파일 하나(`dist/index.html`)라서 어디에든 올려 링크로 나눌 수 있다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 단위 테스트
npm run build    # dist/index.html 한 파일로 빌드
```

## 조작

| | 키보드/마우스 | 터치 |
|---|---|---|
| 이동 / 달리기 | WASD, 방향키 / Shift | 왼쪽 스틱 / 달리기 버튼 |
| 점프 | 스페이스 (길게 누르면 높이 뜀) | 점프 버튼 |
| 잠수 | C 또는 Ctrl, 스페이스로 떠오르기 | 잠수 버튼 |
| 시점 | 마우스, Q/E | 화면 드래그 |
| 1인칭 / 3인칭 | T | 상단 버튼 |
| 멀어지기 (우주까지) | 마우스 휠, −/= | −/+ 버튼 |
| 지도 / 소리 | N / M | 지도 누르기 / 상단 버튼 |

## 지구 데이터

- 지형과 해저: NOAA ETOPO1 (10분 간격). 높이는 1칸 = 100m로 과장해서 에베레스트가 약 88칸, 챌린저 해연이 약 -109칸이다.
- 땅 색: NASA 블루 마블 위성사진. 밤에는 NASA 야간 도시 불빛이 켜진다.
- 나라 이름: Natural Earth 국경 (1:110m).
- 해: 오늘 날짜의 계절(적위)과 게임 시각으로 실제 위치를 계산한다. 하루는 10분.

데이터는 `scripts/earth-data.py`, `scripts/countries-data.py`로 다시 만들 수 있다.

## 구조

| 폴더 | 역할 |
|---|---|
| `src/earth` | 행성: 좌표계(`geo`), 고도(`elevation`), 색과 식생(`surface`), 쿼드트리 지형(`terrain`), 바다, 대기, 해, 구 위의 물리(`body`), 나무, 뉴욕(`nyc`), 랜드마크. |
| `src/physics` | 고정 60Hz 물리. 매 스텝 발밑의 접평면을 평평한 땅으로 보고 계산한다. 손맛 상수는 `world.ts` 맨 위. |
| `src/sky` | 하늘 색, 해·달·별·오로라, 구름. |
| `src/audio` | WebAudio로 합성하는 효과음과 환경음. |
| `src/fx`, `src/cube`, `src/input`, `src/hud.ts`, `src/world/minimap.ts` | 입자, 큐브, 입력, 화면 UI, 위성사진 지도. |
