# 큐브 월드

귀여운 3D 큐브가 다양한 지형과 생명체, 마을과 도시를 자유롭게 탐험하는 웹 게임. Three.js + TypeScript + Vite.
빌드 결과는 파일 하나(`dist/index.html`)라서 어디에든 올려 링크로 나눌 수 있다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 단위 테스트
npm run build    # dist/index.html 한 파일로 빌드
```

## 조작

| | 키보드/마우스 | 터치 |
|---|---|---|
| 이동 | WASD, 방향키 | 왼쪽 스틱 |
| 점프 | 스페이스 (길게 누르면 높이 뜀) | 점프 버튼 |
| 시점 | 마우스 드래그, Q/E | 화면 드래그 |
| 시간 빨리감기 / 소리 | T / M | 상단 버튼 |

## 구조

| 폴더 | 역할 |
|---|---|
| `src/physics` | 고정 60Hz 물리. 중력, 가변 점프, 코요테 타임, 점프 버퍼, 비탈, 나무/바위 충돌, 물에 뜨기. 손맛 상수는 `world.ts` 맨 위. |
| `src/terrain` | 시드 기반 지형: 대륙/섬/바다, 언덕, 산악, 강, 기후에 따른 생태계(초원·벚꽃 숲·단풍 숲·사막·열대·설원). 물리와 렌더링이 같은 함수를 쓴다. |
| `src/world` | 청크 스트리밍, 지하 동굴과 하늘, 생태계별 자연물, 정착지, 생명체, 물, 렌더링. |
| `src/sky` | 낮밤 순환, 하늘·해·달·별·구름. |
| `src/audio` | WebAudio로 합성하는 효과음, 환경음, 오르골 멜로디. 소리 파일 없음. |
| `src/fx` | 먼지/물보라/반짝임 입자. |
| `src/cube`, `src/input`, `src/hud.ts` | 큐브, 입력, 화면 UI. |

## 월드 둘러보기

- 시작 지점 표지판을 따라 동굴 입구로 들어가면 지하로, 계단을 올라가면 고산 지대으로 이동한다. 돌아올 때는 각 지역의 입구나 계단을 반대 방향으로 지나간다.
- 미니맵의 위쪽은 북쪽이다. 꽃·바·도는 정착지, 굴·계는 동굴과 계단을 나타낸다.

- 시작 지점에서 약 100~250m 떨어지면 크리스탈 평원과 버섯 숲이 나온다. 밤에 더 밝게 빛난다.
- 바다와 강에서는 헤엄치고 물속으로 잠수해 물고기 떼를 볼 수 있다.

- 세 곳의 마을과 도시 광장에서 각기 다른 건물과 랜드마크를 만날 수 있다.
